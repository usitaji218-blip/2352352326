# OnRe — Allocation Checker

Одностраничный статический прототип allocation checker в стиле OnRe. Проект работает без сборки и зависимостей: открой `index.html` или запусти локальный сервер.

## Запуск

```bash
python3 -m http.server 8080
```

Затем открой `http://localhost:8080`.

## Что внутри

- `index.html` — разметка страницы, навигация, карточка проверки и диалоги;
- `css/style.css` — тёмная адаптивная тема, сетка, фоновые эффекты и состояния компонентов;
- `js/main.js` — выбор кошелька, error-state, faux Cap-проверка, toast и доступность клавиатурой.

Выбор кошелька в текущем прототипе намеренно не вызывает реальное расширение и не запрашивает подписи: после выбора показывается состояние ошибки, как на референсе. Для production-версии нужно подключить безопасный wallet adapter и backend/API проверки отдельно.
